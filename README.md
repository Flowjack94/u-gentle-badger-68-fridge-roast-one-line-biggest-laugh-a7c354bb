## Entry

One line (164 characters) roasting a smart fridge — it texts its owner at 3 a.m.
about expired milk, a burnt-out ice maker, and a health-inspector complaint:

> My smart fridge texted me at 3 a.m. to announce the milk expired 47 days ago, the ice maker has filed for burnout, and it cc'd the health inspector on ticket #4821.

## How to run

```sh
python3 main.py   # writes the entry to /output/entry.txt
```
